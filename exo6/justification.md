# Pourquoi nous demandons un bonus
Nous avons fait tous les exercices du TP, y compris les deux exercices optionnels (4 et 6). Nous avons commencé par le tutoriel NumPy. Ensuite, nous avons codé nous-mêmes un classifieur aléatoire et un KNN pour prédire l'accord d'un prêt. Le meilleur résultat est de 86,5 % avec seulement 3 variables. Nous avons ensuite appliqué le KNN à MNIST (90,6 %), puis à Fashion-MNIST (81,4 %) et à CIFAR-10 (environ 27 %). Pour ces trois jeux de données, nous avons gardé la même méthode et choisi le meilleur k par validation croisée. Nous avons aussi utilisé le KNN pour la régression (satisfaction de vie selon le PIB) et répondu aux questions théoriques. Avant ce TP, nous connaissions peu le KNN et NumPy. Nous avons appris qu'ajouter plus de variables ne rend pas toujours le modèle meilleur. Nous avons aussi vu que la valeur de k change beaucoup les résultats : un k trop petit rend le modèle sensible au bruit, et un k trop grand donne une prédiction trop lisse. Enfin, les calculs avec NumPy sans boucles (broadcasting) sont beaucoup plus rapides, et le KNN sur les pixels bruts marche bien pour des images simples mais mal pour des images complexes comme CIFAR-10.
